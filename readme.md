# 💻 Portfólio Profissional – Samira de Oliveira Hirosue

## 📌 Descrição do portfólio

O projeto consiste no desenvolvimento de um portfólio profissional com o objetivo de apresentar meu perfil como estudante de Desenvolvimento de Sistemas, minhas tecnologias e ferramentas em aprendizado, minha formação acadêmica e alguns projetos desenvolvidos durante minha trajetória de estudos.

## 🛠️ Tecnologias utilizadas

Para o desenvolvimento do projeto foram utilizadas as seguintes tecnologias e ferramentas:

* HTML: responsável pela estruturação e organização do conteúdo da página.

* CSS: utilizado para personalização de estilos e ajustes visuais.

* Bootstrap: utilizado para criação do layout responsivo, menus, cards, botões e carousel.

## 🌐 Link do site publicado

https://samirahirosue.github.io/portfolio/

## ⚙️ Explicação do funcionamento do projeto

O portfólio funciona como um site de apresentação profissional, organizado em diferentes seções para facilitar a navegação e a visualização das informações.

Sua estrutura é composta por:

1. Menu de navegação: permite acessar as principais áreas do site, como Perfil, Projetos e Contato.

2. Carousel de imagens: apresenta três imagens em formato de slides, com navegação automática e controles para avançar ou retornar.

3. Perfil profissional: apresenta uma foto, uma breve descrição pessoal, localização, área de interesse, formação e objetivo profissional.

4. Tecnologias e ferramentas: exibe ícones e nomes das tecnologias estudadas, como HTML5, CSS3, Bootstrap, Python, GitHub e VS Code.

5. Projetos: apresenta três exemplos de projetos, com imagens, títulos e descrições.

6. Contato: disponibiliza links para envio de e-mail, acesso ao GitHub e ao LinkedIn.

7. Rodapé: apresenta os créditos e o ano de desenvolvimento do portfólio.

## 🆕 Descrição do recurso novo adicionado – Seção Formação Acadêmica

Como melhoria do projeto, foi adicionada uma nova seção chamada Formação Acadêmica, com o objetivo de apresentar de maneira mais organizada e destacada minha trajetória educacional na área de tecnologia.

## 💡 Explicação de como o novo recurso foi implementado

A seção Formação Acadêmica foi implementada utilizando HTML5 e componentes de layout do Bootstrap.

Foi criado um elemento `<section>` com o identificador formacao, permitindo organizar o conteúdo em uma área independente da página.

Para sua construção, foram utilizados:

* Container: responsável por centralizar e limitar a largura do conteúdo.

* Título e descrição: utilizados para identificar a seção e apresentar uma breve introdução.

* Grid do Bootstrap: utilizado para centralizar o conteúdo e organizar sua disposição.

* Card: utilizado para destacar as informações da formação acadêmica.

* Ícone de capelo (🎓): adicionado para representar visualmente a educação e a formação.

* Classes de estilização: utilizadas para aplicar espaçamentos, bordas arredondadas, sombras e alinhamento.

A estrutura principal foi desenvolvida com as seguintes tags HTML:

* `<section>`: cria a seção Formação Acadêmica.

* `<div>`: organiza os elementos e aplica as classes do Bootstrap.

* `<h2>`: apresenta o título da seção.

* `<h5>`: identifica o curso realizado.

* `<p>`: apresenta o nome da instituição e a modalidade do curso.
